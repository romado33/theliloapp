# CursorTheLiloApp

Personal project. Full-stack vacation-experience booking app (guest + host features). Originally generated by Lovable, synced to GitHub.

## Stack

Vite + React + TypeScript, shadcn-ui, Tailwind CSS, Supabase (Postgres + auth). Playwright for e2e. ESLint configured.

## Run

```bash
npm install
npm run dev          # Vite dev server
npm run build        # production build
npm test             # unit
npx playwright test  # e2e
```

## Layout

- `src/` — app code
- `supabase/` — migrations + client config
- `e2e/` — Playwright tests
- `__tests__/` — unit tests (comprehensive coverage)
- `.env` / `.env.local` / `.env.example` — config (see SECURITY_NOTICE.md)
- `dist/` — build output (gitignored)

## Gotchas

- **`.env` was previously committed** containing Supabase keys. Rotate keys if not already done, and verify `.env` is gitignored before next commit.
- `VITE_DEV_BYPASS_PASSWORD` must **never** be set in production — dev-only auth bypass.
- Lovable may push auto-commits back to this repo — expect occasional automated changes.
